# שפת גוף ב-30 יום

אפליקציית ווב בעברית (RTL, מותאמת למובייל) ללימוד שפת גוף ותקשורת.

- 30 שיעורים קצרים. שיעור חדש נפתח ביום שאחרי שמסיימים את המבחן של השיעור הקודם.
- בכל שיעור: הרעיון, על מה להסתכל, מה זה אומר ומה לא, מה המחקר אומר (כשרלוונטי), דוגמה מהחיים ותרגיל להיום.
- אחרי כל שיעור: מבחן של 3 שאלות אמריקאיות עם הסבר לכל תשובה.
- אחרי שיעורים 7, 14, 21 ו-28: מבחן חזרה שבועי (שאלה אחת מכל שיעור). אחרי שיעור 30: מבחן מסכם של 12 שאלות.
- מסך התקדמות: רצף ימים, רצף שיא, לוח ימי לימוד, ציונים ושיעורים שהושלמו.
- ההתקדמות נשמרת ב-`localStorage` של הדפדפן (מפתח `bodylang.v1`).

## הרצה

אין שלב בנייה. פותחים את `index.html` בדפדפן, או מגישים את התיקייה בכל שרת סטטי:

```
npx serve body-language
```

## קבצים

| קובץ | תוכן |
| --- | --- |
| `index.html` | מעטפת הדף והניווט התחתון |
| `styles.css` | עיצוב, כולל מצב כהה |
| `app.js` | ניתוב, נעילת שיעורים לפי יום, מבחנים, רצף ושמירה |
| `lessons-a.js`, `lessons-b.js` | תוכן השיעורים 1–15 ו-16–30. בכל שאלה, האפשרות הראשונה היא הנכונה, והאפליקציה מערבבת את הסדר בהצגה |

## בדיקה

במסך ההתקדמות, תחת "הגדרות", אפשר לפתוח את כל השיעורים בבת אחת כדי לעבור על התוכן בלי לחכות יום.
