# שפת גוף ב-30 יום

משחק לימוד בעברית (RTL, מותאם למובייל) לשפת גוף ותקשורת. אפשר להתקין אותו בטלפון כאפליקציה (PWA) והוא עובד גם בלי אינטרנט.

## שכבת המשחק

- **מפה** של 30 שלבים בשבילים מתפתלים, עם שלבי בונוס (מבחני חזרה) ומבחן מסכם.
- **XP ורמות:** 12 רמות, מ"מתבונן מתחיל" עד "אמן הסבירות". ה-XP מחושב מההתקדמות עצמה (ציון הכי טוב, תרגילים, רצף), כך שניסיון חוזר נותן XP רק כשהוא משפר ציון.
- **כוכבים** לכל שלב (3 מתוך 3 = שלושה כוכבים), **28 הישגים**, **משימות יומיות** (לקרוא, לעבור מבחן, לעשות את התרגיל בחיים).
- **פיד למידה** בסגנון טיקטוק: 237 כרטיסים קצרים, אחד בכל מסך, בגלילה אנכית אינסופית. ארבעה סוגים: טיפ, מיתוס או עובדה, "מה הייתם עושים?" ומשימת שטח. מכסה את 30 נושאי השיעורים ועוד 16 נושאים (שיחות וידאו, מרחב אישי, ראיון עבודה, משא ומתן, התנצלות, לומר לא ועוד). כרטיסים חדשים מוצגים קודם, ואפשר לשמור כרטיסים.
- **כרטיסי תמונה:** 17 איורים (פנים, יציבה, מבט מלמעלה על קבוצות ומרחק) עם שאלה "מה רואים בתמונה?". מופיעים בפיד ובשיעורים הרלוונטיים.
- **כרטיסי קול:** שתי גרסאות של אותו משפט, שהטלפון מקריא (אם יש בו קול בעברית).
- **סיפורים אינטראקטיביים:** ראיון עבודה, שותף לדירה ופגישת צוות. לכל בחירה יש תוצאה.
- **חזרה על טעויות:** כל שאלה שטעיתם בה חוזרת אחרי יום, שלושה ימים ושבוע.
- **אימון לפי נושא ומסלולים:** 8 מסלולים (עבודה, זוגיות, הורות, מסכים ועוד).
- **יומן משימות, גיבוי בקוד, תזכורת ביומן, תעודת סיום, ומסכי פתיחה למשתמש חדש.**
- **מבחני השיעורים:** 5 שאלות במאגר של כל שיעור, ובכל פעם נבחרות 3.
- **הדמיית שיחה:** 8 שיחות (זוגיות, חברים, שקרים, שכנים, שירות, דייט, עבודה, משפחה). בוחרים תשובה בכל תור, רואים את תגובת הצד השני ומד מצב השיחה; על תשובה לא טובה מקבלים תיקון והסבר, ואפשר לנסות שוב.
- **"מה השתבש פה?"** (12 שיחות קצרות) ו**"סדרו נכון"** (6 תהליכים), וכרטיסים בנושאים זוגיות, חיי יום יום, משפחה, חברים ושירות.
- **ארגז כלים:** 25 מצבים מהחיים (לפתוח שיחה, לבקש העלאה, להתנצל, להרגיע ויכוח ועוד): מה אומרים, מה עושים עם הגוף, ממה להימנע ולמה זה עובד.
- **שאלות יישום קשות:** 60 שאלות שבהן כל האפשרויות סבירות. מבחן של שלב כולל 2 כאלה, ומבחני החזרה והמסכם מבוססים עליהן.
- **סבב בזק:** 60 שניות של מיתוס או עובדה, טעות עולה 3 שניות, עם שיא אישי.
- רצף תשובות נכונות במבחן, צלילים ורטט (אפשר לכבות בהגדרות), קונפטי בציון מושלם ובעליית רמה.

- 30 שיעורים קצרים. שיעור חדש נפתח ביום שאחרי שמסיימים את המבחן של השיעור הקודם.
- בכל שיעור: הרעיון, על מה להסתכל, מה זה אומר ומה לא, מה המחקר אומר (כשרלוונטי), דוגמה מהחיים ותרגיל להיום.
- אחרי כל שיעור: מבחן של 3 שאלות אמריקאיות עם הסבר לכל תשובה.
- אחרי שיעורים 7, 14, 21 ו-28: מבחן חזרה שבועי (שאלה אחת מכל שיעור). אחרי שיעור 30: מבחן מסכם של 12 שאלות.
- מסך התקדמות: רצף ימים, רצף שיא, לוח ימי לימוד, ציונים ושיעורים שהושלמו.
- ההתקדמות נשמרת ב-`localStorage` של הדפדפן (מפתח `bodylang.v1`).

## התקנה בטלפון

האפליקציה צריכה כתובת https כדי שאפשר יהיה להתקין אותה. הדרך הפשוטה: GitHub Pages מהמאגר הזה.

1. ב-GitHub: Settings → Pages.
2. תחת Build and deployment: Source = Deploy from a branch, Branch = הענף שבו נמצאת התיקייה, תיקייה `/ (root)`, Save.
3. אחרי דקה-שתיים האפליקציה תהיה בכתובת `https://<user>.github.io/<repo>/body-language/`.
4. בטלפון: אנדרואיד (כרום) → תפריט ⋮ → "התקנת אפליקציה". אייפון (ספארי) → שיתוף → "הוספה למסך הבית".

## הרצה

אין שלב בנייה. פותחים את `index.html` בדפדפן, או מגישים את התיקייה בכל שרת סטטי:

```
npx serve body-language
```

## קבצים

| קובץ | תוכן |
| --- | --- |
| `index.html` | מעטפת הדף והניווט התחתון |
| `styles.css` | עיצוב, כולל מצב כהה |
| `app.js` | ניתוב, נעילת שלבים לפי יום, מבחנים, XP, רמות, הישגים, רצף ושמירה |
| `manifest.webmanifest`, `sw.js`, `icons/` | התקנה כאפליקציה ועבודה בלי אינטרנט |
| `feed-a.js`, `feed-b.js`, `feed-c.js` | כרטיסי הפיד (טיפים, מיתוס או עובדה, תרחישים, משימות שטח) |
| `lessons-hard.js` | שאלות יישום קשות |
| `tools.js` | ארגז הכלים |
| `lessons-extra.js` | שאלות נוספות לכל שיעור |
| `pics.js` | האיורים וכרטיסי התמונה |
| `sims.js` | הדמיות השיחה |
| `feed-d.js` | "מה השתבש פה?", "סדרו נכון" ונושאים חדשים. נטען אחרי `pics.js` כדי לשמור על מזהי הכרטיסים |
| `stories.js` | הסיפורים האינטראקטיביים |
| `lessons-a.js`, `lessons-b.js` | תוכן השיעורים 1–15 ו-16–30. בכל שאלה, האפשרות הראשונה היא הנכונה, והאפליקציה מערבבת את הסדר בהצגה |
